# START_HERE_DI_EXHIBIT_BOOKS

A start-here index for Grounded DI LLC’s Evidence and Decision Library and its companion cross-domain benchmark volume.

## What this repository is

This repository is the navigation and naming surface for a structured collection of Grounded DI technical, governance, audit, public-record, legal, and case-study materials.

The supplied September 2026 collection package contains nine books organized into four subject groups: Exhibits, Public Record, Case Studies, and Legal. Book 10 is a separate reconciled benchmark volume covering the 83/83 cross-domain record.

The collection preserves historical labels inside the source materials while using stable current display titles and filenames for review. No new sequential book numbers are inferred where the catalog intentionally retains an existing gap.

## Start Here

Choose the reading route that matches your purpose:

- General orientation: Selected Exhibits - Foundations, then Selected Exhibits - Systems and Applications.
- Legal review: Law Firm Decision and Evidence, followed by BriefWise - Harvey Benchmark Audit.
- Governance and chronology: Public Record - Chronology, The Evidence Arc, and The Control Plane.
- Technical case studies: Before Reality Resolved - DI Weather Station and MathWise / Erdos - Mathematical Record.
- Benchmark review: Cross-Domain 83/83 Record (Book 10).
- Full collection review: use the Master Book Catalog in the September 2026 collection package.

The reconciled v1.1 edition is a 24-page evidence book describing an 83-position series using Google Research IFEval items. Its stated boundary is:

| Measure | Recorded status |
|---|---:|
| Published prompt positions | 83 |

The book expressly distinguishes the local strict-pass record from a complete official IFEval score. It is not an official IFEval leaderboard result, an independently verified benchmark, or proof of a particular underlying model identity.

The benchmark source record is associated with the [Benchmarks-Cross-Domain repository](https://github.com/Grounded-DI/Benchmarks-Cross-Domain). The PDF records repository snapshot identifier d3f4235e346a.

## How to review

1. Use the canonical display title to select the relevant book.
2. Use the standardized filename when locating the corresponding PDF in the publication package.
3. Read the Master Book Catalog before interpreting historical labels or book numbering.
4. Keep local checks, official evaluator executions, independent verification, and product status as separate propositions.
5. Follow the source repository and commit references for technical reproduction or deeper audit.

## Repository status

This repository is intentionally a start-here index. At the current publication point, the GitHub repository contains the README navigation surface; the binary book package and companion Book 10 PDF remain separately identified publication artifacts.

The index does not claim that the books are a deployed product, an official certification, or an independently validated benchmark collection. It provides a stable naming, provenance, and review structure for the records that follow.
